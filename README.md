# Mein Plan

Persönlicher Tagesplaner (Studium, Lernblöcke, Gym, Projekte) mit Fortschritt, XP und Serien.
Läuft als Webseite über GitHub Pages; die Daten liegen privat in Supabase (Login nötig).

- `index.html`: die App
- `backend.js`: Anbindung an Supabase (Daten, Dateien, Anmelden, Datenumzug)
- `config.js`: Supabase-Adresse und öffentlicher Schlüssel
- `setup.sql`: Tabellen und Regeln für Supabase (einmal ausführen)
- `zug/`: Live-Zugverbindungen Grafing ⇄ Hochschule München
- `vendor/supabase.js`: supabase-js 2.117.3 (MIT-Lizenz, siehe `vendor/supabase.LICENSE`)

Im Repo liegen keine persönlichen Daten.
